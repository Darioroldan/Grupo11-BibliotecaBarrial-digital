# Análisis – Biblioteca barrial
**Proyecto:** 
Mi Emprendimiento Digital (AED2) – Grupo 11 
**Tema:** Colecciones y Listas (Clase 6) 
## Problema La biblioteca barrial lleva el control de préstamos en cuadernos. 
El problema es que es difícil saber qué libros están disponibles y a quién se ha prestado. 
El sistema usa listas para manejar libros, socios y préstamos. 

## Actor:
**Encargado de biblioteca**
## Casos de uso 
**CU01: Registrar libro** 

Descripción: Agregar un libro al catálogo. 

**CU02: Registrar socio**

Descripción: Dar de alta a un socio. 

**CU03: Registrar préstamo**

Descripción: Prestar un libro disponible a un socio. 

**CU04: Registrar devolución**

Descripción: Marcar un libro prestado como devuelto. 

**CU05: Listar libros prestados** 

Descripción: Mostrar la lista de los libros que están prestados.
